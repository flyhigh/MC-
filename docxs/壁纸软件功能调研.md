| 能力 | 出处 |
| --- | --- |
| 缩放模式 `none/fill/uniform/uniformFill/auto`,视频/GIF/图片/全局各一套 | Lively `WallpaperScaler` |
| 硬件解码开关、外部编解码器、播放器后端可选(mpv / WMF / WebView2 / CEF) | Lively `VideoPlayer` 等 |
| 音频可视化、媒体信息(NowPlaying) | Lively `LivelyMessageSystemNowPlaying` |
| 视差(鼠标/陀螺仪) | lwp |
| 时间轴壁纸(按时间段换) | ScreenPlay |

### 2.5 多显示器

Lively 是这块的标杆,取值都是一手枚举:

- 排布:`per`(每屏不同)/ `span`(一张跨所有屏)/ `duplicate`(所有屏同一张);
- 屏幕识别:`deviceName` / `deviceId` / `screenLayout`;
- 暂停粒度:`perdisplay`(哪块屏跑全屏就停哪块)/ `all`;
- 音频路由:`selection`(只在选定屏出声)/ `all`;
- 记住上次选中的屏(`RememberSelectedScreen`)。

### 2.6 性能与省电(最值得抄的一块)

Lively 把"什么时候别跑"做成了规则表,每个场景三选一:**`pause`(暂停)/ `ignore`(不管)/ `kill`(杀进程)**,一手来自 `AppRules` 枚举与 `SettingsModel`:

| 规则 | 场景 |
| --- | --- |
| `AppFocusPause` | 有前台应用时 |
| `AppFullscreenPause` | 有全屏应用/游戏时(README 称 0% CPU/GPU) |
| `BatteryPause` | 用电池时 |
| `RemoteDesktopPause` | 远程桌面会话中 |
| `PowerSaveModePause` | 系统进入节能模式 |

配套还有:进程监控算法 `foreground / all / gamemode / grid`(`grid` 是把桌面切格,**只给被窗口盖住的格子暂停**)、监控间隔 `ProcessTimerInterval`、网格铺砖尺寸与覆盖率阈值、启动超时 `WallpaperWaitTime`(超时就杀掉)。

### 2.7 声音

全局音量(0–100)、"只在桌面时出声"、音频暂停算法 `none/cursor/primaryscreen`(指针或主屏离开就静音)、多屏音频路由、可视化专用音频设备。

### 2.8 屏保 / 锁屏 / 系统整合

- 屏保:复用当前壁纸或另设一套、空闲 1–120 分钟触发、宽限期、锁屏等待超时、音频空闲检测、OLED 防烧屏提醒、空屏黑屏、淡入、屏保音量、恢复后自动锁屏;
- 把壁纸**截图**设成锁屏图 / 桌面图(`LockScreenAutoWallpaper`、`DesktopAutoWallpaper`);
- 任务栏主题跟随:透明 / 模糊 / Fluent / 自定义色 / **壁纸平均色** / 壁纸平均色的 Fluent 版;
- 稳定性:任务栏崩溃重启的容错计时、安全退出、WorkerW 挂载方式可选。

### 2.9 界面与入口

Lively 的界面文件(一手:全部 `Views/Pages` 列表)基本就是一张"成熟壁纸应用的页面地图":

`Library`(库)/ `AddWallpaper` 三步向导(选文件 → 填元数据 → 生成)/ `ChooseDisplay`(选屏)/ `ControlPanel`(布局 + 屏保布局 + 自定义布局)/ `Gallery`(在线社区的 8 个页面)/ `Settings`(General / Performance / Wallpaper / Screensaver / System)**五个分页** / `AppTheme` / `AppUpdate` / `FindMoreApps` / `Help` / `About` / `DepthEstimate`(AI 页)/ `DebugLog` / 诊断菜单。

入口与形态:

- 托盘常驻 + 右键菜单(Lively `SysTrayIcon`、巨应壁纸、lwp 都是"二次启动直接开设置");
- 界面模式 `normal / lite / headless`(轻量/无界面,只留引擎);
- 主题:深/浅/跟随系统 + 背景材质(Mica 等)、应用自定义背景图;
- 语言(可社区翻译)、开机自启、图层大小(`TileSize`)、动态图标(`LiveTile`)、缩略图信息角标(`WaterMarkTile`);
- 拖拽导入(把文件/网页/zip 拖进窗口即用);
- `FindMoreApps`(顺手推荐自家其他应用)—— 产品化的小细节。

### 2.10 壁纸属性面板(定制)

这是 Lively 最"值钱"的设计:每个壁纸在目录里放一份 `LivelyProperties.json`,应用**按 schema 自动生成控件**,不需要为每个壁纸写界面。schema 支持的控件类型(一手):

`slider`(带 min/max/step)、`textbox`、`dropdown`(items)、`folderDropdown`(按文件过滤选文件)、`button`、`label`、`color`(带吸管 `EyeDropper`)、`checkbox`。

另外有独立的**属性托盘**(`LivelyPropertiesTray`),不打开主窗也能调参。

### 2.11 AI 能力(目前唯一把 AI 做进壁纸主流程的开源项目)

| 项目 | AI 功能 | 交互范式 |
| --- | --- | --- |
| Lively `DepthEstimateWallpaperView` | 单图深度估计(MiDaS,ONNX),生成可随鼠标视差的 2.5D 壁纸 | 选图 → (缺模型则**下载模型并显示进度**) → 运行 → **展示深度图预览** → 自动**入库**并关闭对话框 |
| wallpaper-box | 文生图壁纸(OpenAI Images 兼容端点) | AI 配置是**独立页面**(不塞进全局设置),带自己的设置按钮;有"提示词结构建议"文档 |
| cc-haha / openpets | 用 AI 的状态驱动桌宠动作 | 状态 → 动作映射;openpets 明确"不把提示词/代码/路径显示在气泡里" |

共同点:AI 功能都是**独立页面 + 明确的进度 + 结果预览 + 落地到库**,而且都留了"没配 Key/没下模型"的降级路径。

## 三、MC 壁纸现状对照

| 能力 | 行业是否标配 | MC 壁纸现状 | 结论 |
| --- | --- | --- | --- |
| 程序化/着色器壁纸 | 少见(Lively 靠 Shadertoy 网页代打) | ✅ wgpu + DirectComposition,10–50 ms 出图 | **我们的差异点,保持** |
| 面板(控制台) | ✅ | ✅ Slint 液态玻璃,预设 + 参数 + 亮度 + 动效 | 继续做,但**缺页面结构** |
| 壁纸库(存储) | ✅ | ✅ 已落盘(`%APPDATA%\MC壁纸\library\<指纹>.json`,指纹去重) | 存储有了,**界面没有** |
| 壁纸库(浏览/搜索/缩略图) | ✅ 标配 | ❌ | **优先补** |
| 托盘图标 + 右键菜单 | ✅ 标配 | ❌ 只有桌面快捷方式 + 单实例把面板叫前台 | **优先补**(成本极低,收益极高) |
| 开机自启 | ✅ 标配 | ❌ | 优先补 |
| 按前台应用/全屏/电池调策略 | ✅ 标配 | ❌ | 中期,和"随工作状态变化"同源 |
| 亮度自动适配 | 少见(Lively 无) | 半成品:亮度是**手动滑杆** | 中期:接系统亮度/时段 |
| 多显示器 | ✅ | 架构预留,未实现(决策 #6 先单屏) | 按原计划延后 |
| 屏保 / 锁屏图 | ✅ | ❌ | 远期 |
| 属性面板(每壁纸自定义参数) | ✅(Lively 的强项) | 部分:固定 3 个参数 | 中期:`WallpaperSpec` 已经有参数槽位,可做"动态槽位" |
| 打包分享 / 社区 | ✅(大厂标配) | ❌ | 远期;先把本地库做好 |
| AI 生成(文生图/深度图) | 少数 | ❌ 决策已选云端,但**尚未接入** | 中期,按 Lively 范式:独立页 + 进度 + 预览 + 入库 |
| 桌宠 | 少数 | ❌ | 已规划,是 MC 壁纸的"对话入口",排期另定 |
| 视频/网页壁纸 | ✅(但非我们定位) | ❌ | **不抄**:定位是程序化着色器 + AI 生成,不做播放器 |

## 四、给界面的建议(按性价比排序)

**P0 — 小工作量、高感知(建议下一轮就做)**

1. **托盘图标 + 右键菜单** ✅ 2026-10-14 已实现:打开控制面板 / 换一个预设 / 暂停-继续渲染 / 开机自启 / 退出。(Lively、巨应壁纸、lwp 全都有;我们之前关掉面板就"没有入口了")
2. **面板分页骨架** ✅ 2026-10-14 已实现:`壁纸 / 库 / 设置` 三段页签;库与设置先放占位页,后面的功能才有地方放。
3. **壁纸库页(网格 + 缩略图 + 搜索 + 一键切换 + 删除)**:库已经落盘,只差界面;缩略图可以让渲染器离屏渲一张小图存到库目录。
4. **开机自启开关 + 状态行**(比照 Lively `Startup` / `SysTrayIcon`)。托盘菜单里的勾选项 ✅ 已实现;面板「设置」页里的开关与状态行待做。
5. **当前壁纸信息条**:标题、指纹短码、来源(预设 / AI 生成)、"已保存到库"的时间。

**P1 — 中期(需要一点架构)**

6. **自动化规则页**:按前台应用 / 全屏 / 电池三档(`pause` / `ignore` 两档就够),复用"随工作状态变化"那套状态机。
7. **动态属性槽位**:把 `param-a/b/c` 升级成声明式控件(滑杆/下拉/颜色),向 Lively 的 `LivelyProperties` 靠 —— `WallpaperSpec` 已经是最好的落点。
8. **AI 生成页**:独立页面 + Key 管理 + 进度 + 预览 + 入库,照抄 Lively 深度估计页的流程骨架即可;降级要明确(没 Key 时页面直接说明)。
9. **历史 / 回滚**:状态变化不进库(决策 #5),但"最近用过的 N 张"应该可一键回退。

**P2 — 远期**

10. 多显示器、屏保 / 锁屏图、`.mcwp` 打包分享、社区、桌宠面板(与壁纸渲染联动)。

**明确不做**(v1 之前):Unity/Godot 运行时、在线社区。

> 修订(2026-10-14):视频 / GIF / 网页壁纸播放器原先按"与程序化着色器定位冲突"列为不做,
> **已由用户拍板纳入范围** —— 见《MC壁纸-需求与技术方案》§12.1 决策 #4 与 §12.2 待定项 7。
> 定位上也理顺了:着色器场景与外部素材**并存**,前者是"AI 现场生成"的落点,后者是"用户自带素材"的落点。
